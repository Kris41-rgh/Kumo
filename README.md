# Kumo
Красивое приложение погоды для старых iPhone на iOS 6 (armv7), написано на Objective-C и Theos. Текущая погода и прогноз на 3 дня, ветер, влажность и давление, несколько городов со свайпом, геолокация и поиск, тёмная и светлая темы, свой цвет, три вида экрана, анимация дождя и снега, котики вместо осадков и совет дня. Без API-ключей.
